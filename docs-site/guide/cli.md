# CLI 用法

所有入口都走同一个可执行文件，用 flag 切换行为：

| Flag | 说明 |
| --- | --- |
| `-tui` | 启动终端 UI（默认若未指定其它模式） |
| `-web` | 启动 Web UI（浏览器访问） |
| `-e "<prompt>"` | headless 模式：发送一条消息并跑完一轮 |
| `-s <id>` | 恢复指定会话并进入终端 UI（回放历史 + 继续） |
| `--fork <id>` | 以某会话为蓝本派生新会话后进入 |
| `-view <id>` | 以只读浏览模式进入终端 UI |
| `-replay <id>` | 非交互回放某会话的事件流（Trajectory 视图），打印后退出 |
| `-replay <id> -w` | 打印该会话的 Web 只读分享链接，不输出正文 |
| `-ls` | 列出全部会话（id / 时间 / 条数 / 标题） |
| `-search <关键词>` | 在全部会话正文里检索，列出命中会话与上下文片段 |
| `-image <路径>` | 给 `-e` 的这条消息附一张图片，可重复 |
| `-archive <天数>` | 把早于 N 天的会话导出成按月分组的 Markdown 归档后退出 |
| `-archive-prune` | 归档后删除原会话文件（破坏性，需配合 `-archive`） |
| `-model <名字>` | 本次运行使用指定主模型（来自 `llm.models`） |
| `-aux <名字>` | 本次运行指定辅助模型（上下文摘要用） |
| `-web-host <host>` | `-replay -w` 打印分享链接时使用的基地址 |
| `-tools` | 打印当前 shell / 已启用工具 / 技能清单 |
| `-v` | 打印版本与已加载插件 |
| `-c <path>` | 指定配置文件路径（默认程序目录下的 `config.json`） |

::: info 示例
`./gsh -replay 20260101-120000-ab12 -w` 默认输出 `http://localhost:8934/#/share/20260101-120000-ab12`；把 Web UI 跑在对外域名上时用 `-web-host` 指定真实基地址，见[会话管理](./sessions)。
:::

## 首次运行

程序以**可执行文件所在目录**为锚点解析配置、数据、日志与技能目录，与当前工作目录无关。首次运行会在程序目录生成 `config.json` 并在启动时打印四个路径（程序目录 / 配置 / 数据 / 日志），填入 `api_key` 后即可使用。

## 带图片执行

```bash
./gsh -e "这张报错截图是什么问题" -image ./shot.png
```

`-image` 可重复，图片按本地路径在**发送时**读取并编码成 data URL，会话里只留路径不存 base64——历史文件不会因为几张图膨胀成几十 MB。单图上限 8MB；读不到（路径写错、文件被删）时不会让整轮失败，那一张会被跳过并在提示文本里留下说明。

只有 `-e` 支持 `-image`；交互模式用终端 UI 的 `/image` 命令（见[终端 UI](./tui)），Web UI 用输入框左侧的附件按钮。

Web UI 的麦克风按钮是另一条路：语音转成文字**填进输入框**，由你删改后再自己发送，不会自动发出。识别准确率撑不起「语音直接进模型」——错一个路径或标识符就得重来一轮；落成可编辑文本后，错字只是改几个字符。浏览器不支持 Web Speech API 时按钮不出现。

## 归档旧会话

```bash
./gsh -archive 30          # 30 天前的会话 → .gsh/session/archive/YYYY-MM.md
./gsh -archive 30 -archive-prune   # 归档后删除原会话文件
```

归档只做**导出**，不动原始会话：搜索、`-replay`、只读分享照样能用。想把磁盘腾出来是另一件事，要显式加 `-archive-prune`。按月归到同一个 Markdown 里，方便成批查阅。
