# 终端 UI

终端 UI 用 bubbletea + lipgloss 实现，视觉规范按实际落地：顶部圆角标题条、左侧蓝色竖条的用户块、等宽工具行、底部带左边条的输入框。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Enter` | 发送（Shift+Enter 换行） |
| `Esc` | 运行中停止当前轮 / 关闭浮层 |
| `Ctrl+C` | 退出 |
| `Ctrl+P` | 打开会话列表（↑/↓、j/k 选择，Enter 打开，d 删除） |
| `Ctrl+E` | 把当前会话导出为 Markdown 文件 |
| `Tab` | 循环切换权限档：只读 → 标准 → 完全 → 计划 |
| `Ctrl+T` | 循环切换展示档：简洁 → 标准 → 详细 → 完全 |
| `a` / `A` / `d` | 权限确认浮层中：允许 / 总是允许 / 拒绝 |

## 斜杠命令

| 命令 | 作用 |
| --- | --- |
| `/help` | 显示帮助浮层 |
| `/sessions` | 打开会话列表（等同 Ctrl+P） |
| `/readonly` | 在「只读浏览」与「可编辑继续」之间切换 |
| `/export` | 导出当前会话为 Markdown（等同 Ctrl+E） |
| `/new` | 开新会话 |
| `/clear` | 清空当前会话 |
| `/model [名字]` | 列出或切换主模型 |
| `/aux [名字]` | 列出或切换辅助模型（摘要用） |
| `/mode [档位]` | 查看或切换权限档（`read_only` / `standard` / `full` / `plan`） |
| `/detail [0-3]` | 设置展示档 |
| `/tools` | 列出当前可用工具 |
| `/todo` | 查看当前任务的计划清单 |
| `/memory` | 查看长期记忆内容与文件位置 |
| `/history <关键词>` | 在历史会话里检索 |
| `/image <路径>` | 挂一张本地图片到下一句；`clear` 清空待发队列 |

## 展示档

过程信息的默认可见度可调，避免长任务里工具输出刷屏：

| 档位 | 工具行 | 参数 | 结果正文 | 思考 |
| --- | --- | --- | --- | --- |
| 简洁 | 隐藏 | 隐藏 | 隐藏 | 隐藏 |
| 标准 | 显示 | 显示 | 前 40 行 | 折叠一行预览 |
| 详细 | 显示 | 显示 | 全文 | 全文 |
| 完全 | 显示 | 显示 | 全文 | 全文 |

## 交互式权限

标准档位下，`bash` / `write` / `edit` / `make_dir` / `move` / `copy` / `delete` 等高风险工具执行前会弹出确认浮层：

- `a` 本次允许
- `A` 总是允许（计入本进程白名单，直到退出）
- `d` 或 `Esc` 拒绝

只读档位由全局 guard 直接拦截写工具，完全档位跳过确认。

## 计划模式

`/mode plan`（或 Tab 循环到「计划」）是「只读 + 先出方案」的组合档：权限按只读执行，同时把 `planMode` 标记打进运行时，系统提示要求模型先给出可执行的方案并停下等确认，而不是试探性地去写。

它和只读档的区别是行为约束的方向：只读档只是「不许动手」，计划模式还要求「说清打算怎么动手」——改哪些文件、每处改什么、风险在哪。

## 只读浏览模式

用 `-view <id>` 或会话内 `/readonly` 进入只读浏览：可滚动查看历史、可用 Ctrl+P 切换会话，但禁止发送新消息、隐藏输入框。适合复盘或演示。
