# 介绍

gsh 是一个微内核 + 插件化的终端式 AI Agent。一个内核同时驱动终端 UI、Web UI 与 CLI，三者完全对等；会话以 append-only JSONL 落盘，可恢复、可分叉、可回放、可只读分享。

- 微内核
- 插件化
- TUI / Web / CLI 三端对等
- 会话回放
- 只读分享
- 交互式权限
- 工作区白名单

## 为什么是 gsh

- **一个内核，多种界面**：同一套 agent loop 与工具执行，既能在终端用 bubbletea 交互，也能在浏览器看轨迹，也能用命令行一次性跑完。
- **会话是第一公民**：每次运行都落盘成可回放的事件流，不怕中断，可事后复盘或分享给他人只读查看。
- **安全默认**：标准档位对高风险工具做交互式确认；工作区路径白名单阻止越界读写；删除即真删。
