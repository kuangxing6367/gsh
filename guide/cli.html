CLI 用法 ​

所有入口都走同一个可执行文件，用 flag 切换行为：

Flag说明
-tui启动终端 UI（默认若未指定其它模式）
-web启动 Web UI（浏览器访问）
-e "<prompt>"headless 模式：发送一条消息并跑完一轮
-s <id>恢复指定会话并进入终端 UI（回放历史 + 继续）
--fork <id>以某会话为蓝本派生新会话后进入
-view <id>以只读浏览模式进入终端 UI
-replay <id>非交互回放某会话的事件流（Trajectory 视图），打印后退出
-replay <id> -w打印该会话的 Web 只读分享链接，不输出正文
-ls列出全部会话（id / 时间 / 条数 / 标题）
-tools打印当前 shell / 已启用工具 / 技能清单
-v打印版本与已加载插件
-cfg <path>指定配置文件路径（默认 ./config.json）

示例

./gsh -replay 20260101-120000-ab12 -w 会输出 https://gsh.zgric.top/#/share/20260101-120000-ab12（前提是 Web UI 自托管的分享域名，见会话管理）。
