终端 UI ​

终端 UI 用 bubbletea + lipgloss 实现，视觉规范按实际落地：顶部圆角标题条、左侧蓝色竖条的用户块、等宽工具行、底部带左边条的输入框。

快捷键 ​

按键作用
Enter发送（Shift+Enter 换行）
Esc运行中停止当前轮 / 关闭浮层
Ctrl+C退出
Ctrl+P打开会话列表（↑/↓、j/k 选择，Enter 打开，d 删除）
Ctrl+E把当前会话导出为 Markdown 文件
a / A / d权限确认浮层中：允许 / 总是允许 / 拒绝

斜杠命令 ​

命令作用
/help显示帮助浮层
/sessions打开会话列表（等同 Ctrl+P）
/readonly在「只读浏览」与「可编辑继续」之间切换
/export导出当前会话为 Markdown（等同 Ctrl+E）
/new开新会话
/clear清空当前会话

交互式权限 ​

标准档位下，bash / write / edit / make_dir / move / copy / delete 等高风险工具执行前会弹出确认浮层：

  • a 本次允许
  • A 总是允许（计入本进程白名单，直到退出）
  • d 或 Esc 拒绝

只读档位由全局 guard 直接拦截写工具，完全档位跳过确认。

只读浏览模式 ​

用 -view <id> 或会话内 /readonly 进入只读浏览：可滚动查看历史、可用 Ctrl+P 切换会话，但禁止发送新消息、隐藏输入框。适合复盘或演示。
